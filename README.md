# DK 104 公司介紹票選

同事讀三個版本的 104 公司介紹，選一版、每版可寫修改建議，票寫進 Google 試算表。

| 頁面 | 用途 |
|---|---|
| `index.html` | 投票（填部門姓名 → 讀版本 → 選一版、寫建議 → 送出） |
| `board.html` | 公開結果：票數、部門、建議原文，不顯示姓名 |
| `results.html` | 管理頁：要密碼，看得到姓名與完整名單 |

- 版本內容在 `versions.js`，要改字或加一版改這裡就好。
- 收票網址在 `config.js` 的 `scriptUrl`。
- 收票程式 `apps-script.gs` 綁在試算表上（含管理頁密碼，不放進 repo）。
- 版本順序每台電腦第一次打開時隨機打亂，避免排第一個的比較容易被選。
- 同一個人（部門＋姓名）送出多次，只算最後一次。
